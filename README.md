# Sales Forecasting & Business Analytics

## Project Overview
Analyzed 48 months of historical sales data (2018–2021) for Joe's Stone Crab using Microsoft Excel to forecast monthly sales for 2022 and identify seasonal trends.

## Tools & Techniques
- Microsoft Excel
- Linear Regression
- Seasonal Index Analysis
- Time-Series Forecasting
- Data Visualization

## Key Findings
- **R²: 0.839** — Regression explained 83.9% of variation in deseasonalized historical sales.
- **Historical MAPE: 2.27%** — Strong fit to historical sales data.
- **Peak Sales:** January
- **Lowest Sales:** September

## Business Recommendations
- Adjust staffing and inventory based on seasonal demand.
- Plan promotions during slower months.
- Compare actual sales with forecasts to improve future planning.
